# SSG Server

A Discord-like website with Discord authentication and Torn API integration.

## Features

- 🔐 Discord OAuth Authentication
- 🎮 Torn API Integration
- 📊 Real-time Discord Server Data
- 👥 User Management
- 🔗 Channel Linking

## Prerequisites

- Node.js (v16 or higher)
- npm or yarn
- Discord Application (for OAuth)
- Torn API Key
