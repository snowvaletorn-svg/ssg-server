Player Stats Endpoint

Get Player Stats Endpoint

Endpoint

GET /api/v1/get-stats

Required Parameters

Parameter Type Description Example

Rate Limiting

20 requests per minute per IP address

curl -X GET "https://ffscouter.com/api/v1/get-stats?key=abc123def456ghi&targets=2675763,1426381"

Example Response

[
  {
    "player_id": 267456763,
    "fair_fight": 5.39,
    "bs_estimate": 2989885521,
    "bs_estimate_human": "2.99b",
    "bss_public": 123456,
    "last_updated": 1747333361,
    "source": "premium",
    "premium_insights_available": true,
    "distribution": {
      "last_updated": 1747333361,
      "distribution_human": "STR (60%) SPD (30%)",
      "stats_percentage": {
        "strength": 60,
        "speed": 30
      }
    }
  },
  {
    "player_id": 142625381,
    "fair_fight": null,
    "bs_estimate": null,
    "bs_estimate_human": null,
    "bss_public": null,
    "last_updated": null,
    "source": "bss",
    "distribution": null,
    "premium_insights_available": false

]

Premium Distribution Field

Premium callers receive distribution when a latest usable data is available for that target. The nested last_updated value is the source timestamp in Unix seconds, distribution_human is a short summary string, and stats_percentage contains the top two stats as rounded percentages of the total.

Premium insights flag

Each object includes premium_insights_available (boolean). When true, FFScouter has qualifying insights for that target: stat distribution and/or enhanced estimates when your key has premium access. Premium subscribers may already see those fields in the same response; non-premium callers see the flag without the underlying data. It is false when no such insights is available for that target.

Player Stats History Endpoint

Get Player Stats History Endpoint

Endpoint

GET /api/v1/get-stats-history

Required Parameters

Parameter Type Description Example
key string Your API key (16 alphanumeric characters) abc123def456ghi
target integer Single player ID to fetch history for 1844049

Optional Parameters

Parameter Type Description Default
limit integer Number of summarized buckets to return (1-100). Each bucket is a 6-hour window; values are median-smoothed. 100
from integer Unix timestamp start (inclusive) null
to integer Unix timestamp end (inclusive) null
sort string Sort order for history timestamps ("asc" or "desc") desc

Example Request

curl -X GET "https://ffscouter.com/api/v1/get-stats-history?key=abc123def456ghi&target=1844049&limit=3"

Example Response

{
  "player_id": 1844049,
  "bucket_window_seconds": 21600,
  "first_estimate_timestamp": 1710000000,
  "most_recent_timestamp": 1769295473,
  "history": [
    {
      "timestamp": 1769292000,
      "bss_public": 87438,
      "bs_estimate": 1987805000,
      "bs_estimate_human": "1.99b",
      "source": "bss"
    }
  ]
}

Notes

  • History is summarized in 6-hour windows (bucket_window_seconds: 21600). Each entry's timestamp is the window start; bss_public and bs_estimate are the median of all raw values in that window, matching the player view on the website.
  • Each bucket in history includes source, always "bss" for stored public estimates
  • Results are ordered from most recent to oldest by default (use sort=asc for oldest first)
  • History is limited to a maximum of 100 buckets per request
  • History collection started on 1st Feb 2026, so estimate timestamps before this date are not available

Player Flights Endpoint (Premium)

Current trip and recent completed flights

Returns one player’s in-progress flight (if any) and up to ten completed trips. You must call this with a registered API key whose owner has active premium. Timelines and travel-type labels are estimates derived from public game data, not official Torn values.

Endpoint

GET /api/v1/player-flights

Required Parameters

Parameter Type Description Example
key string Your FFScouter API key (16 alphanumeric characters). abc123def456ghi
target integer The Torn player ID to fetch flights for 1844049

Rate limiting

Up to 100 requests per minute per premium account (all keys tied to the same user share this limit). This endpoint does not use the same per-IP throttle as most other routes. A small allowlist of owning player IDs (site configuration) may bypass this limit entirely.

Caching

Successful responses are cached for 10 seconds per target player ID.

Example Request

curl -X GET "https://ffscouter.com/api/v1/player-flights?key=abc123def456ghi&target=1844049"

Example Response

    "latest_arrival_time": 1710010800,
    "travel_method": "Airline",
    "book_likely_being_used": true
  },
  "recent_flights": [
    {
      "takeoff_time": 1709900000,
      "status_description": "Traveling to China",
      "earliest_arrival_time": 1709905000,
      "latest_arrival_time": 1709909000,
      "travel_method": "PI",
      "book_likely_being_used": false,
      "approx_landing_time": 1709912000
    }
  ]
}

Top-level response

Field Type Description
player_id integer Same as the target you requested
current object|null The active trip, if one is known; otherwise null
recent_flights array Up to ten completed trips, newest first

Fields on each flight object

Objects under current and recent_flights share the fields below, except where noted.

Field Type Description

status_description string|null Travel status text from the game when the trip was observed
earliest_arrival_time integer|null Unix timestamp (seconds), lower bound of the estimated arrival window
latest_arrival_time integer|null Unix timestamp (seconds), upper bound of the estimated arrival window

book_likely_being_used boolean|null For an in-progress trip, whether the Book perk was treated as active when estimating arrival times. For completed trips, our best yes/no after the flight finished; null when we cannot tell.

Activity Tracker (Premium)

Time-bucketed activity from FFScouter’s scanner data (five-minute observations aggregated into your chosen bucket size). Requires active premium on the API key owner. Timestamps are Unix seconds in UTC (TCT). Each response returns at most 5,000 buckets.

Endpoints

Method Path Purpose
GET /api/v1/activity/player One player’s activity score per bucket
GET /api/v1/activity/faction Faction aggregate: active members per bucket

Required Parameters (both endpoints)

Parameter Type Description Example
key string Your FFScouter API key (16 alphanumeric characters) abc123def456ghi
start integer Range start, Unix timestamp (seconds), inclusive. Must not be in the future or before tracking began. 1710000000
end integer Range end, Unix timestamp (seconds), exclusive. Must be greater than start. 1710086400

Endpoint-specific required parameters

Endpoint Parameter Description
Player target Torn player ID
Faction faction_id Torn faction ID (uses stored roster membership)

Optional Parameters

Parameter Type Description Default
bucket integer Bucket width in seconds: 300 (5 min), 900 (15 min), or 3600 (1 hour). Buckets align from start. 300

Rate limiting

Per premium account (all keys for the same owner share the bucket):

  • Player activity: 60 requests per minute
  • Faction activity: 10 requests per minute

Example Request (player)

curl -X GET "https://ffscouter.com/api/v1/activity/player?key=abc123def456ghi&target=1844049&start=1710000000&end=1710086400&bucket=900"

    { "ts": 1710000000, "activity_score": 1 },

}

Field Type Description

Hit Calling Endpoints (Premium)

Faction target claims

Hit Calling lets premium players mark Torn targets they intend to hit and share that queue with everyone in their faction. You must use a registered API key whose owner has active premium and is currently in a tracked faction on FFScouter. Each claim shows who called the target, when the claim was made, and when it expires. Faction leaders can set how long claims last (from 30 seconds up to 15 minutes) on the My Faction dashboard; until that is changed, the maximum is 15 minutes.

Poll GET /api/v1/hit-calling/claims to see every active claim in your faction. The response groups them under claims.faction, keyed by target player ID. Multiple members may claim the same target; claims for one target are always returned in call order (first claim first). The same member may claim the same target more than once—each call adds another queue entry at the back (they can appear multiple times in the list for that target).

Endpoints

Method Path Purpose
GET /api/v1/hit-calling/claims List all active faction claims
POST /api/v1/hit-calling/claim Claim a target (adds a new queue entry; repeat claims on the same target append at the back)
POST /api/v1/hit-calling/unclaim Release your claim(s) on one target, or one specific claim by ID
POST /api/v1/hit-calling/wipe Release every claim you have placed

Required parameters

All four routes require your API key (query string or JSON body). POST /claim requires target_player_id. POST /unclaim requires either target_player_id (release all of your claims on that target) or claim_id (release one claim), or both when you want to verify the claim belongs to that target.

Parameter Type Description Example
key string Your FFScouter API key (16 alphanumeric characters). abc123def456ghi
target_player_id integer Required for POST /claim. For POST /unclaim, releases every active claim you hold on that target when used alone. 555111
claim_id string (UUID) Optional for POST /unclaim. When provided (with or without target_player_id), removes only that claim if it belongs to you. 2f84b4fb-8f26-4e79-8be3-8f0e9d988f26

Rate limiting

GET /claims is limited to 60 requests per minute per premium account. POST /claim is limited to 30 requests per minute per premium account. POST /unclaim is limited to 30 requests per minute per premium account. POST /wipe is limited to 10 requests per minute per premium account. All keys tied to the same user share the limit for each endpoint type. You may hold at most 30 active claims at the same time (each queue entry counts, including multiple claims on the same target).

Required Developer Actions

When registering a user with FFScouter, you MUST provide them with a link to the FFScouter homepage to read the Data Policy and Terms and Conditions. This is required by the rules of Torn. Failing to do so is breaking a Torn rule. You should prompt the user to read this and have them tick a box or click a button in some way to confirm they have done this before submitting a register request.

Find Targets Endpoint

Get Target Players Endpoint

Endpoint

GET /api/v1/get-targets

Required Parameters

Parameter Type Description Example
key string Your API key (16 alphanumeric characters) abc123def456ghi

Optional Parameters

Parameter Type Default Description
preset string null Preset mode for quick filtering ("respect", "level")
minlevel integer 1 Minimum player level (inclusive). If provided without maxlevel, filters level >= minlevel (1-100)
maxlevel integer 100 Maximum player level (inclusive). If provided without minlevel, filters level <= maxlevel (1-100)
inactiveonly integer 1 Filter for inactive players only (14+ days since last action) (0 or 1)
minff float 1.00 Minimum fair fight value (inclusive). If provided without maxff, filters FF >= minff (≥1.0)
maxff float 3.00 Maximum fair fight value (inclusive). If provided without minff, filters FF <= maxff (≥1.0)
limit integer 20 Maximum number of targets to return (1-50)
factionless integer 0 Filter for factionless players only (0 or 1)

Preset Modes

Respect Preset

Optimized for gaining maximum respect per attack. When using this preset:

  • Only "key" and "limit" parameters are allowed
  • Automatically filters for fair fight range 2.00-3.00
  • Shows only inactive players (14+ days since last action)
  • Results ordered by battle stat score (descending)
Level Preset

Optimized for level-based targeting. When using this preset:

  • Only "key" and "limit" parameters are allowed
  • Automatically filters for fair fight ≤ 3.00
  • No minimum fair fight restriction
  • Results ordered by level (descending)

Rate Limiting

5 requests per minute per IP address

Example Requests

Basic Request (Randomized Results)
curl -X GET "https://ffscouter.com/api/v1/get-targets?key=abc123def456ghi"
Respect Preset
curl -X GET "https://ffscouter.com/api/v1/get-targets?key=abc123def456ghi&preset=respect"
Level Preset
curl -X GET "https://ffscouter.com/api/v1/get-targets?key=abc123def456ghi&preset=level"
Custom Filter
curl -X GET "https://ffscouter.com/api/v1/get-targets?key=abc123def456ghi&minlevel=20&maxlevel=50&minff=1.5&maxff=2.5&inactiveonly=1&limit=25"
Factionless Players Only
curl -X GET "https://ffscouter.com/api/v1/get-targets?key=abc123def456ghi&factionless=1"
